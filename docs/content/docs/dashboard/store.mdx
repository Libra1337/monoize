## Open the Store

Open **Store** at `/dashboard/store`. Select **Balance**, **Plans**, or **Redeem code**.

![Store](/images/en/store.webp)

Use the currency control to show CNY or USD. The control updates the balance, current-month usage, prices, bonuses, received amounts, and plan quotas.

Monoize refreshes the USD/CNY rate at most once every 15 minutes. It keeps the last valid rate when a refresh fails.

## Recharge balance

1. Select a recharge product or enter a custom amount.
2. Review the recharge amount, bonus, and actual received amount.
3. Select one enabled payment Channel.
4. Create the order.

Monoize saves the payment attempt before it contacts the Provider. Stripe then opens its hosted Checkout page.

Alipay submits a signed official payment form. WeChat Native shows a scannable QR code. WeChat H5 opens the official mobile payment page.

Do not create another attempt when the Provider result is unknown. Wait for Monoize to reconcile the existing attempt.

The Store checks the order every two seconds after checkout. It stops after payment and fulfillment finish, the order closes, or the order expires.

Open `/dashboard/orders` to review the order. Check the payment state and the fulfillment state separately.

Monoize grants the balance only after it verifies the provider payment. An administrator cannot mark an unpaid order as paid or fulfilled.

## Configure Stripe callbacks

Set the Stripe Webhook endpoint to `https://lynshen.org/api/store/callbacks/{channel_id}`. Replace `{channel_id}` with the Stripe Channel ID.

Subscribe to `checkout.session.completed` and `checkout.session.async_payment_succeeded`. Save the endpoint signing secret in the encrypted Stripe credential.

## Configure Alipay callbacks

Set the Alipay asynchronous notification URL to `https://lynshen.org/api/store/callbacks/{channel_id}`. Replace `{channel_id}` with the Alipay Channel ID.

Save the Alipay App ID, seller ID, merchant private key, Alipay public key, and environment in Store Management. Monoize verifies RSA2 and returns `success` only after it stores the verified event.

## Configure WeChat Pay callbacks

Set the WeChat Pay notification URL to `https://lynshen.org/api/store/callbacks/{channel_id}`. Replace `{channel_id}` with the WeChat Pay Channel ID.

Save the merchant ID, App ID, API v3 key, merchant certificate serial, merchant private key, platform certificate serial, and platform public key. Monoize verifies the platform signature and decrypts each payment resource before fulfillment.

## Buy a plan

Select a plan and a payment Channel. Each plan can apply several quota windows at the same time. A window can use 5 hours, 12 hours, a day, a week, a month, or a custom whole-hour duration.

Monoize stores plan quotas in CNY. The Store shows each quota as a rounded whole CNY or USD amount.

## Qualify SQLite for plans

Stop the Monoize application before you change the SQLite quota Gate. Set `MONOIZE_DATABASE_DSN` to the target SQLite database.

Import a passed drill manifest into the `next` slot:

```bash
monoize-store-ops quota-gate import --slot next --manifest ./quota-manifest.json
```

Read the compatibility fingerprint from the command output. Promote the imported manifest before you start the new application version:

```bash
monoize-store-ops quota-gate promote --expected-fingerprint <fingerprint>
```

The command rejects PostgreSQL, an oversized manifest, invalid JSON, and a manifest that does not match the live SQLite environment.

## Redeem a code

Enter one unused code in **Redeem code**. A code grants balance or activates a plan. Redemption does not use a payment Channel and does not create an order.

## Manage the Store

Administrators open `/dashboard/store-admin`. Use its four tabs to manage products, payment Channels, orders, and redemption codes.

- Set separate custom recharge limits for CNY and USD.
- Add an Alipay, WeChat Pay, Stripe, or draft HTTP Channel. Use a built-in icon, an HTTPS image URL, or an uploaded image.
- Open an existing official Channel. Enter every credential field and your current Admin password. Select **Replace credential**. Monoize encrypts the new version, retires the prior version, and disables the Channel.
- Keep an HTTP Channel disabled in Milestone 1.
- Review payment state and fulfillment state separately. Do not use a manual completion action.
- Generate 1 through 20 single-use codes. Copy the plaintext codes when Monoize shows them.
