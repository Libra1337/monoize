## 查看公告

打开仪表板侧边栏中的铃铛。对话框列出每条公告的类型圆点、标题、内容与发布时间。置顶公告带置顶标记。

新公告在进入仪表板时自动弹出。打开对话框即把列出的公告标记为已读。选择**今日不再提醒**可在当天(北京时间)内不再自动弹出。已读状态按账号存储,跨设备同步。

## 发布公告

在 `/dashboard/announcements-admin` 打开**公告管理**。仅 `admin` 与 `super_admin` 会话可访问。

1. 选择**新建公告**。
2. 填写标题、内容与类型(通知、成功、警告、错误)。
3. 打开**置顶**开关可将公告保持在顶部。
4. 打开**已发布**开关可启用或停用。
5. 保存。

停用的公告对所有用户从铃铛中消失。删除公告会一并删除其已读状态。
