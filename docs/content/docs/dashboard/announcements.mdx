## Read announcements

Open the bell in the dashboard sidebar. The dialog lists every announcement with its type dot, title, content, and publication time. Pinned announcements show a pin marker.

New announcements pop up automatically when you enter the dashboard. Opening the dialog marks the listed announcements as read. Select **Close for today** to suppress the popup for the rest of the Beijing day. Read state is stored per account, so it follows you across devices.

## Publish announcements

Open **Announcements** at `/dashboard/announcements-admin`. Only `admin` and `super_admin` sessions can open this page.

1. Select **New announcement**.
2. Fill the title, content, and type (Info, Success, Warning, or Error).
3. Toggle **Pinned** to keep the announcement on top.
4. Toggle **Published** to enable or disable it.
5. Save.

Disabled announcements disappear from the bell for every user. Deleting an announcement removes its read state too.
