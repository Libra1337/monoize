## 檢視公告

開啟儀表板側邊欄中的鈴鐺。對話框列出每則公告的類型圓點、標題、內容與發布時間。置頂公告帶置頂標記。

新公告在進入儀表板時自動彈出。開啟對話框即把列出的公告標記為已讀。選擇**今日不再提醒**可在當天(北京時間)內不再自動彈出。已讀狀態按帳號儲存,跨裝置同步。

## 發布公告

在 `/dashboard/announcements-admin` 開啟**公告管理**。僅 `admin` 與 `super_admin` 會話可存取。

1. 選擇**新建公告**。
2. 填寫標題、內容與類型(通知、成功、警告、錯誤)。
3. 開啟**置頂**開關可將公告保持在頂部。
4. 開啟**已發布**開關可啟用或停用。
5. 儲存。

停用的公告對所有使用者從鈴鐺中消失。刪除公告會一併刪除其已讀狀態。
