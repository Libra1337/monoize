---
title: Apeiron
description: 在智能体驱动的无限画布上创作图片与视频。
---

在 `/dashboard/studio` 打开**创作工作台**。页面列出你的画布项目。选择**新建项目**，从空白画布或模板开始。

## 画布

每个项目是一块无限画布。节点承载工作：

- **剧本**：剧本正文，智能体在这里写初稿。
- **分镜**：一行分镜，含画面描述、运镜与时长。
- **图片**：生成的首帧画面。
- **视频**：生成的片段。把图片节点连到视频节点即可作为首帧。

节点可自由拖动，画布可缩放平移。小地图显示全局面貌。

## 智能体

在底部输入框写下需求并发送。智能体可以写剧本、拆分镜、生成分镜提示词，并启动图片或视频任务。一句话即可完成整部短片：直接要求跑完整管线。

每个动作都是独立的计费步骤。失败与取消的步骤全额退款。

## 工单

使用工具栏的**生图**或**生视频**按钮，绕过对话直接发起单次生成。

## 资产

打开 `/dashboard/studio/assets` 浏览所有项目生成的图片与视频。

## 管理

打开 `/dashboard/studio-admin` 管理模板、监控任务，并设置智能体模型与默认视频上游。视频通道使用 `openai_video`、`fal_video` 或 `replicate` 提供方类型。在提供方页面像普通通道一样添加即可。
