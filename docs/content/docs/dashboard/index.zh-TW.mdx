## 存取儀表板

在瀏覽器開啟 Monoize 的監聽位址，預設是 `http://localhost:8080`。release 建置在同一程序中提供儀表板、API 和指標。

![儀表板概覽](/images/en/dashboard.webp)

## 帳號與角色

- 安裝後註冊第一個帳號。第一個註冊的帳號自動成為 `super_admin`。即使公開註冊已關閉，此規則仍然生效。
- `super_admin` 可以管理使用者、系統設定、Provider 和計費。
- `admin` 帳號管理營運資源。
- `user` 帳號管理自己的 API 金鑰、日誌和餘額。

## 帳戶類型

每個帳號有一個帳戶類型：一般使用者或企業使用者。帳戶類型與 `user`、`admin`、`super_admin` 角色互相獨立。

Group 也有一個帳戶類型。Provider、Channel、模型項目和價格繼承所屬 Group 的帳戶類型。模型市集、模型解析、Channel 選擇、路由、價格預估和最終計費只使用目前帳戶類型的資源，絕不回退到另一種類型。

`super_admin` 在**使用者**頁面切換使用者的帳戶類型。切換需要二次確認，因為它會在同一個交易中永久刪除該使用者現有的全部 API Key。錢包餘額、方案權益、訂單、兌換歷史、請求日誌和歷史用量保持不變。

Group、Provider 和價格頁面提供**目錄範圍**控制項。清單不會混合兩種類型。

## 管理區域

| 區域 | 用途 |
| --- | --- |
| 儀表板 | 流量、費用和健康狀態總覽 |
| 服務供應商 | Provider、Channel、模型對應、健康狀態、變換 |
| Token 管理 | API 金鑰、配額、模型限制、變換 |
| 日誌 | 請求日誌與擷取檢視器 |
| 模型資料庫 | 從 Models.dev 匯入的模型中繼資料與定價 |
| 商店 | 餘額儲值、方案、訂單、付款 Channel 和兌換碼 |
| 使用者管理 | 帳號、餘額與計費流水 |
| 系統設定 | 系統設定、全域變換、請求擷取開關 |
| 子帳號 | 帳戶子使用者、餘額分發與用量 |

## 語言

儀表板支援 English、简体中文、繁體中文和日本語。在使用者選單中切換語言。
