---

`/dashboard/studio` で**スタジオ**を開きます。ページにキャンバスプロジェクトが一覧表示されます。**新規プロジェクト**を選ぶと、空白キャンバスまたはテンプレートから始められます。

## キャンバス

各プロジェクトは無限キャンバスです。ノードが作業を担います：

- **脚本**：脚本本文。エージェントがここに草案を書きます。
- **カット**：絵コンテの 1 行。描写、カメラ、長さを持ちます。
- **画像**：生成された先頭フレーム。
- **動画**：生成されたクリップ。画像ノードを接続すると先頭フレームになります。

ノードは自由にドラッグでき、キャンバスはズームとパンに対応します。ミニマップに全体が表示されます。

## エージェント

下部の入力欄に依頼を書いて送信します。エージェントは脚本の起草、カット分割、プロンプト合成、画像・動画ジョブの開始ができます。完全なパイプラインを依頼すれば、一文で短編映画が完成します。

各操作は課金対象のステップです。失敗とキャンセルのステップは全額返金されます。

## ワークオーダー

ツールバーの**画像**または**動画**ボタンで、対話を介さず単発生成できます。

## アセット

`/dashboard/studio/assets` で全プロジェクトの生成画像と動画を閲覧できます。

## 管理

`/dashboard/studio-admin` でテンプレート管理、実行監視、エージェントモデルと既定の動画上流を設定します。動画チャネルは `openai_video`、`fal_video`、`replicate` のプロバイダー種別を使います。プロバイダーページで通常チャネルと同様に追加します。
