title: 收入报表
description: 查看每日收入、模型收入来源与排除用户。
---

## 打开收入报表

在 `/dashboard/admin/revenue` 打开**收入报表**。该页面仅对 `admin` 与 `super_admin` 会话可见。

每天覆盖北京时间 00:00 至 24:00。收入是已记录的请求扣费之和。充值与订单金额不计入收入。

## 查看每日表格

1. 设置**开始日期**与**结束日期**。默认范围为最近 30 天。
2. 阅读每日行。每行显示日期、收入、调用次数、Token 数量，以及收入最高的模型与其收入。
3. 展开一行，查看该日全部模型与全部用户，均按收入降序排列。用户行显示用户名、用户 ID、收入、调用次数与 Tokens。

没有收入的日期不会显示。当日数据实时来自请求日志。历史日期来自每日汇总表，Monoize 在每个北京日 0 点后结算。

## 导出 Excel

选择**导出 Excel**。浏览器下载所选日期范围的 `.xlsx` 文件。`Revenue` 工作表按日期升序，每日一行;`Users` 工作表列出每个用户当日的消费:日期、用户 ID、用户名、收入、调用次数与 Tokens。

## 排除用户

**排除用户**卡片列出消费不计入收入的用户。

1. 在搜索框中输入用户名或用户 ID。
2. 在结果中选择该用户。

从名单移除用户后，该用户的消费重新计入收入。两种变更都会重算日志保留期(365 天)内的历史数据。更早的已落库汇总保持原值。

## 数据保留

请求日志保留 365 天。收入报表最多可回看 365 天。
