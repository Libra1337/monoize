title: Revenue Report
description: Review daily revenue, per-model income, and excluded users.

## Open the Revenue Report

Open **Revenue Report** at `/dashboard/admin/revenue`. The page is visible to `admin` and `super_admin` sessions only.

Each day covers Beijing time 00:00 to 24:00. Revenue is the sum of recorded request charges. Recharge and order money is not revenue.

## Read the consumption table

1. Set **From date** and **To date**. Both default to the current day.
2. The main table is flat, like a spreadsheet: one row per user per day, showing the date, username, user ID, revenue, calls, input Tokens, output Tokens, and that day's top model.
3. Click the Day or Revenue header to sort the table. Expand a row to see that user's per-model charges for the day.

Days with no revenue are omitted. The current day updates live from request logs. Past days come from a persisted daily aggregate that Monoize settles after each Beijing midnight.

## Export Excel

Select **Export Excel**. The browser downloads an `.xlsx` file for the selected date range. The `Revenue` sheet has one row per day, ordered by date ascending. The `Users` sheet lists every user's daily consumption: day, user ID, username, revenue, calls, and Tokens. The `User Models` sheet lists every (day, user, model) charge triple.

## Exclude users

The **Excluded users** card lists users whose consumption is not counted as revenue.

1. Type a username or user ID in the search box.
2. Select the user from the results.

Removing a user from the list counts that user's consumption again. Both changes recompute history within the request-log retention window (365 days). Older persisted days keep their existing values.

## Retention

Request logs are retained for 365 days. The revenue report can look back up to 365 days.
