---
title: 創作工作台
description: 在智能體驅動的無限畫布上創作圖片與影片。
---

在 `/dashboard/studio` 開啟**創作工作台**。頁面列出你的畫布專案。選擇**新建專案**，從空白畫布或範本開始。

## 畫布

每個專案是一塊無限畫布。節點承載工作：

- **劇本**：劇本正文，智能體在這裡寫初稿。
- **分鏡**：一行分鏡，含畫面描述、運鏡與時長。
- **圖片**：生成的首幀畫面。
- **影片**：生成的片段。把圖片節點連到影片節點即可作為首幀。

節點可自由拖動，畫布可縮放平移。小地圖顯示全局面貌。

## 智能體

在底部輸入框寫下需求並送出。智能體可以寫劇本、拆分鏡、生成分鏡提示詞，並啟動圖片或影片任務。一句話即可完成整部短片：直接要求跑完整管線。

每個動作都是獨立的計費步驟。失敗與取消的步驟全額退款。

## 工單

使用工具列的**生圖**或**生影片**按鈕，繞過對話直接發起單次生成。

## 資產

開啟 `/dashboard/studio/assets` 瀏覽所有專案生成的圖片與影片。

## 管理

開啟 `/dashboard/studio-admin` 管理範本、監控任務，並設定智能體模型與預設影片上游。影片通道使用 `openai_video`、`fal_video` 或 `replicate` 提供方類型。在提供方頁面像普通通道一樣新增即可。
