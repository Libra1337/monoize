## 開啟收入報表

在 `/dashboard/admin/revenue` 開啟**收入報表**。該頁面僅對 `admin` 與 `super_admin` 會話可見。

每天覆蓋北京時間 00:00 至 24:00。收入是已記錄的請求扣費之和。儲值與訂單金額不計入收入。

## 檢視每日表格

1. 設定**開始日期**與**結束日期**。預設範圍為最近 30 天。
2. 閱讀每日列。每列顯示日期、收入、呼叫次數、Token 數量，以及收入最高的模型與其收入。
3. 展開一列，檢視該日全部模型與全部使用者，均按收入降序排列。使用者列顯示使用者名稱、使用者 ID、收入、呼叫次數與 Tokens。

沒有收入的日期不會顯示。當日資料即時來自請求日誌。歷史日期來自每日彙總表，Monoize 在每個北京日 0 點後結算。

## 匯出 Excel

選擇**匯出 Excel**。瀏覽器下載所選日期範圍的 `.xlsx` 檔案。`Revenue` 工作表按日期升序，每日一列;`Users` 工作表列出每個使用者當日的消費:日期、使用者 ID、使用者名稱、收入、呼叫次數與 Tokens。

## 排除使用者

**排除使用者**卡片列出消費不計入收入的使用者。

1. 在搜尋框中輸入使用者名稱或使用者 ID。
2. 在結果中選擇該使用者。

從名單移除使用者後，該使用者的消費重新計入收入。兩種變更都會重算日誌保留期(365 天)內的歷史資料。更早的已落庫彙總保持原值。

## 資料保留

請求日誌保留 365 天。收入報表最多可回看 365 天。
