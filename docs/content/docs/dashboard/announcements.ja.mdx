## お知らせを確認する

ダッシュボードのサイドバーにあるベルを開きます。ダイアログに種類のドット、タイトル、本文、公開時間付きですべてのお知らせが一覧されます。固定されたお知らせにはピンマークが付きます。

新しいお知らせはダッシュボードに入ったときに自動でポップアップします。ダイアログを開くと、一覧のお知らせが既読になります。**今日は表示しない**を選ぶと、その日(北京時間)は自動ポップアップを停止できます。既読状態はアカウントごとに保存され、デバイス間で同期されます。

## お知らせを発行する

`/dashboard/announcements-admin` で**お知らせ管理**を開きます。`admin` と `super_admin` のセッションのみアクセスできます。

1. **新規お知らせ**を選択します。
2. タイトル、本文、種類(通知・成功・警告・エラー)を入力します。
3. **固定**をオンにすると先頭に表示されます。
4. **公開**をオンまたはオフにします。
5. 保存します。

公開をオフにしたお知らせは全ユーザーのベルから消えます。お知らせを削除すると既読状態も削除されます。
